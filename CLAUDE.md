# Instruções para o Claude

- Ao terminar uma tarefa de front-end (componentes, páginas, estilos, rotas), rode `npm run mobile` em background e informe a URL mostrada no terminal para abrir no celular (mesma rede Wi-Fi). Se o servidor já estiver rodando, apenas informe a URL.
- Não edite `supabase/migrations/` nem `drizzle/`; mudanças de schema são feitas pelo Lovable.
- Não edite arquivos marcados como gerados automaticamente.
